Datenschutzerklärung

Zuletzt aktualisiert: 26. November 2026

Kurz gesagt

PulseCheck läuft auf Ihrem PC. Es erhebt, speichert oder sendet keine personenbezogenen Daten, weder an uns noch an Dritte. Es gibt keine Konten, keine Analyse und keine Werbung.

Was die App ausliest

Für ihre Prüfungen liest die App Informationen über Ihren Computer aus: Hardware- und Betriebssystemdetails, Laufwerks- und Akkuzustand, Sicherheitseinstellungen, Namen installierter Software, Zusammenfassungen des Ereignisprotokolls und die Netzwerkkonfiguration. Diese Informationen bleiben auf Ihrem PC. Sie erscheinen im App-Fenster und, nur wenn Sie Bericht speichern wählen, in einer HTML-Datei, die Sie selbst speichern. Der Bericht enthält den Namen Ihres Computers; entfernen Sie ihn vor dem Teilen, wenn Sie möchten.

Der Reiter Lösungen arbeitet vollständig auf Ihrem PC mit den oben genannten Informationen. Er enthält weder Werbung noch Affiliate-Links, und Ihre Hardware-Liste wird nirgendwohin gesendet.

Was die App über das Netzwerk sendet

Nur der Verbindungstest nutzt das Netzwerk. Er kontaktiert öffentliche Server und sendet keine Informationen über Sie oder Ihren PC, abgesehen von dem, was jede Internetverbindung preisgibt, etwa Ihre IP-Adresse.

  • Ping an Ihren Router, an 1.1.1.1 (Cloudflare) und an 8.8.8.8 (Google)
  • Eine DNS-Abfrage und eine HTTPS-Verbindung zu www.microsoft.com
  • Eine kleine Anfrage an www.msftconnecttest.com zur Erkennung von Captive Portals
  • Optional: ein 10-MB-Download von speed.cloudflare.com für den Geschwindigkeitstest

Was die App ändert

Nichts. PulseCheck arbeitet nur lesend. Es installiert keine Software, ändert keine Einstellungen und schreibt keine Dateien, außer dem Bericht, den Sie speichern lassen.

Diese Website

Diese Seite wird auf GitHub Pages gehostet. Sie verwendet keine Cookies, keine Analyse und keine fremden Schriften oder Skripte. GitHub kann als Host technische Daten wie IP-Adressen nach seiner eigenen Datenschutzerklärung verarbeiten. Downloads liefert GitHub Releases aus.

Open Source und Kontakt

Der vollständige Quellcode ist öffentlich, sodass jede Aussage oben überprüft werden kann. Bei Fragen oder Bedenken eröffnen Sie ein Issue: https://github.com/Brillant000/PulseCheck/issues
