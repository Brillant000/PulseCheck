Política de privacidad

Última actualización: 27 de noviembre de 2026

En resumen

PulseCheck se ejecuta en tu PC. No recopila, almacena ni envía tus datos personales ni a nosotros ni a nadie. No hay cuentas, ni analítica, ni publicidad.

Qué lee la aplicación

Para realizar sus comprobaciones, la aplicación lee información de tu ordenador: hardware y sistema operativo, estado de discos y batería, ajustes de seguridad, nombres del software instalado, resúmenes del registro de eventos y configuración de red. Esa información se queda en tu PC. Aparece en la ventana de la aplicación y, solo si eliges Guardar informe, en un archivo HTML que guardas tú. El informe incluye el nombre de tu equipo, así que quítalo antes de compartirlo si lo prefieres.

La pestaña Soluciones funciona por completo en tu PC con la información anterior. No contiene publicidad ni enlaces de afiliado, y la lista de tu hardware no se envía a ninguna parte.

Si PulseCheck encuentra un error inesperado, guarda detalles técnicos en un archivo de registro en la carpeta PulseCheck de tus datos de aplicación locales. No se envía nada. Si informas de un problema, revisa el archivo antes de compartirlo, ya que puede contener rutas de archivos.

Qué envía la aplicación por la red

Solo la prueba de conexión usa la red. Contacta con servidores públicos y no envía información sobre ti ni sobre tu PC más allá de lo que revela cualquier conexión a Internet, como tu dirección IP.

  • Ping a tu router, a 1.1.1.1 (Cloudflare) y a 8.8.8.8 (Google)
  • Una consulta DNS y una conexión HTTPS a www.microsoft.com
  • Una pequeña petición a www.msftconnecttest.com para detectar portales cautivos
  • Opcional: una descarga de 10 MB desde speed.cloudflare.com para la prueba de velocidad

Qué cambia la aplicación

El análisis no cambia nada. Si pulsas Corregir y confirmas, PulseCheck aplica solo el cambio anunciado: un ajuste de Windows para tu cuenta, un programa de inicio, archivos temporales o una aplicación de Microsoft Store que hayas marcado. No instala software y nunca cambia tu antivirus ni tu cortafuegos. Cada cambio queda registrado en un archivo de registro en la carpeta PulseCheck de tus datos de aplicación locales, y la mayoría se pueden deshacer desde la aplicación.

Este sitio web

Este sitio está alojado en GitHub Pages. No usa cookies, ni analítica, ni fuentes o scripts de terceros. GitHub, como alojamiento, puede tratar datos técnicos como las direcciones IP según su propia declaración de privacidad. Las descargas las sirve GitHub Releases.

Código abierto y contacto

El código fuente completo es público, así que cada afirmación anterior se puede comprobar. Para dudas o inquietudes, abre una incidencia: https://github.com/Brillant000/PulseCheck/issues

Cambios

Si esta política cambia, la nueva versión se publicará aquí con una nueva fecha.
