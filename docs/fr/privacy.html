Politique de confidentialité

Dernière mise à jour : 26 novembre 2026

En bref

PulseCheck s'exécute sur votre PC. Il ne collecte, ne conserve ni n'envoie vos données personnelles, ni à nous ni à quiconque. Il n'y a ni compte, ni outil d'analyse, ni publicité.

Ce que l'application lit

Pour réaliser ses contrôles, l'application lit des informations sur votre ordinateur : matériel et système d'exploitation, état des disques et de la batterie, paramètres de sécurité, noms des logiciels installés, résumés des journaux d'événements et configuration réseau. Ces informations restent sur votre PC. Elles s'affichent dans la fenêtre de l'application et, uniquement si vous choisissez Enregistrer le rapport, dans un fichier HTML que vous enregistrez vous-même. Le rapport contient le nom de votre ordinateur : retirez-le avant de le partager si vous le souhaitez.

L'onglet Solutions fonctionne entièrement sur votre PC à partir des informations ci-dessus. Il ne contient ni publicité ni lien d'affiliation, et la liste de votre matériel n'est jamais envoyée nulle part.

Ce que l'application envoie sur le réseau

Seul le test de connexion utilise le réseau. Il contacte des serveurs publics et n'envoie aucune information sur vous ou votre PC, hormis ce que révèle toute connexion Internet, comme votre adresse IP.

  • Ping vers votre routeur, 1.1.1.1 (Cloudflare) et 8.8.8.8 (Google)
  • Une résolution DNS et une connexion HTTPS vers www.microsoft.com
  • Une petite requête vers www.msftconnecttest.com pour détecter les portails captifs
  • Optionnel : un téléchargement de 10 Mo depuis speed.cloudflare.com pour le test de débit

Ce que l'application modifie

L'analyse ne modifie rien. Si vous cliquez sur Corriger et confirmez, PulseCheck applique uniquement la modification annoncée : un réglage Windows pour votre compte, un programme de démarrage, des fichiers temporaires ou une application du Microsoft Store que vous avez cochée. Il n'installe aucun logiciel et ne modifie ni votre antivirus ni votre pare-feu. Chaque modification est consignée dans un fichier journal du dossier PulseCheck de vos données d'application locales, et la plupart peuvent être annulées depuis l'appli.

Ce site web

Ce site est hébergé sur GitHub Pages. Il n'utilise ni cookies, ni outil d'analyse, ni polices ou scripts tiers. GitHub, en tant qu'hébergeur, peut traiter des données techniques comme les adresses IP selon sa propre politique de confidentialité. Les téléchargements sont servis par GitHub Releases.
