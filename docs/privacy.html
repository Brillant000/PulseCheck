Privacy policy

Last updated: 27 November 2026

The short version

PulseCheck runs on your PC. It does not collect, store or send your personal data to us or to anyone else. There are no accounts, no analytics and no advertising.

What the app reads

To run its checks, the app reads information about your computer: hardware and operating system details, drive and battery status, security settings, names of installed software, event log summaries and network configuration. This information stays on your PC. It appears in the app window and, only if you choose Save report, in an HTML file that you save yourself. The report includes your computer name, so remove it before sharing if you prefer.

The Solutions tab works entirely on your PC from the information above. It contains no advertising and no affiliate links, and your hardware list is never sent anywhere.

If PulseCheck meets an unexpected error, it saves technical details in a log file in the PulseCheck folder of your local app data. Nothing is sent. If you report a problem, check the file before sharing it, as it can contain file paths.

What the app sends over the network

Only the connection test uses the network. It contacts public servers and sends no information about you or your PC beyond what any internet connection reveals, such as your IP address.

  • Ping to your router, to 1.1.1.1 (Cloudflare) and to 8.8.8.8 (Google)
  • A DNS lookup and an HTTPS connection to www.microsoft.com
  • One small request to www.msftconnecttest.com to detect captive portals
  • Optional: a 10 MB download from speed.cloudflare.com for the speed test

What the app changes

Scanning changes nothing. If you press Fix and confirm, PulseCheck applies only the change it announced: a Windows setting for your account, a startup entry, temporary files, or a Microsoft Store app you ticked. It never installs software and never changes your antivirus or firewall. Each change is recorded in a log file in the PulseCheck folder of your local app data, and most changes can be undone from the app.

This website

This site is hosted on GitHub Pages. It uses no cookies, no analytics and no third-party fonts or scripts. GitHub, as the host, may process technical data such as IP addresses under its own privacy statement. Downloads are served by GitHub Releases.

Open source and contact

The complete source code is public, so every statement above can be checked. For questions or concerns, open an issue: https://github.com/Brillant000/PulseCheck/issues

Changes

If this policy changes, the new version is published here with a new date.
